## 目标

提供基于 Python 标准库的伪造 OpenCode 会话与端到端验证框架，能够回放已记录的事件序列、执行合同不变量检查、注入故障并汇总报告，为 Host / Relay / Mobile 实现提供统一的协议验收基线。

## 输入与前置条件

- 冻结的合同清单：`contracts/traces/manifest.json`，版本 1.0.0。
- 合同不变量：INV-002-1（严格单调序号）、INV-002-2（唯一事件 ID）、INV-002-3（仅持久化事件）、INV-001-6（OutcomeUnknown 不自动重试）、INV-003-1（请求去重）、INV-003-4（无自动重试）、INV-003-5（权限绑定）、INV-004-1（快照摘要）、INV-004-3（空洞→Stale）、INV-004-4（压缩边界）。
- Python 3 标准库（`unittest`、`hashlib`、`json`、`argparse`、`pathlib`）。

## 交付物

- `testkit/e2e/__init__.py`：导出 `EventRecord`、`OpenCodeSession`、`NomadE2EHarness` 等公共符号。
- `testkit/e2e/fake_opencode.py`：`OpenCodeSession` 类，支持事件回放、空洞检测（`Stale`）、全恢复（`Live`）、快照摘要（canonical JSON + SHA-256）、重复命令去重、`OutcomeUnknown` 不自动重试、权限首次写入胜出、压缩边界保留。
- `testkit/e2e/harness.py`：`NomadE2EHarness` 类，支持合同清单加载、场景运行、故障注入运行、11 条协议断言，以及命令行入口 `main()`。
- `testkit/e2e/test_fake_opencode.py`：15 条 `unittest` 用例。
- `testkit/e2e/test_harness.py`：13 条 `unittest` 用例。
- 合计 28 条 `unittest`，命令行直接指向模块（`testkit.e2e.test_fake_opencode testkit.e2e.test_harness`）。

## 验收条件

- [x] `OpenCodeSession.apply_events()` 在事件序列存在空洞时将 `_client_freshness` 设为 `Stale`，在完整回放后设为 `Live`。
- [x] 快照摘要采用 canonical JSON（`sort_keys=True`、`separators=(',', ':')`、`ensure_ascii=False`）与 SHA-256。
- [x] `OutcomeUnknown` 状态下会话不自动重试，由调用方显式处理。
- [x] 多条 `INV-*` 合同不变量在 9 条 trace 上全部通过。
- [x] `python3 -m unittest testkit.e2e.test_fake_opencode testkit.e2e.test_harness` 全部通过。
