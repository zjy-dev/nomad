## Decisions and deviations

- The contract is schema-first. INV blocks and state transitions live declaratively in JSON so Host/Relay/Mobile/Runtime can consume the same file without generating language-specific types.
- Excluded from schema: event payload, encryption envelope, transport frame, language-specific types — preserved via the `excluded` array per CON-001 scope.

## Security and privacy

- No encryption fields, no credentials, no prompt/content/diff fields inside the schema. The semantic model is content-agnostic by design.
- `session_id` constrained to opaque `[a-z0-9]+` identifiers (max 64 chars); no user-provided namespaces leak into the contract.
