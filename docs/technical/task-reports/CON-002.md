Frozen the durable/ephemeral event contract for Session Semantics v0, establishing what can be replayed, what must be durably stored, and how delta loss is recovered.

  - Invariants INV-002-1..INV-002-6, including the "delta loss must be recoverable from durable events alone" rule.
  - Unknown-event strategy: fail closed.

## Decisions and deviations

- We chose a minimal payload shape (summary, state_change, tool_name, permission_id, action, reason) rather than a richer event object to keep the durable contract stable. Richer detail belongs in chunk_ref payloads or ephemeral layers.
- Ephemeral categories live outside the JSON contract by design (listed only as documentation) so consumers never accidentally depend on them.

## Security and privacy

- No content field enters the durable schema's required fields. `chunk_ref` (optional) is a bounded pointer, not raw content.
- Unknown event types are fail-closed rather than "best effort" — prevents silent content leakage if the upstream system introduces an unvetted type.
