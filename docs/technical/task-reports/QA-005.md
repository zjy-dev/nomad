## 目标

将 QA-002 的故障注入引擎与 QA-003 的伪造 OpenCode 会话集成，以纯 Python 标准库回放合同清单中的 9 条 trace，施加六种故障（重复 / 乱序 / 丢弃 / 延迟 / 重启 / 磁盘满），验证会话在故障下仍满足序号单调、事件 ID 唯一、仅持久化事件、OutcomeUnknown 不自动重试等协议不变量，形成可机器验证的回归基线。

- [x] 故障注入后回放的事件仍满足序号单调、事件 ID 唯一、仅持久化事件三条核心不变量。
